# v0.20.3 修复与验证记录

日期：2026-09-19。

## 行为

- 已加载客户端在正常停服时收到维护通知，显示「服务器正在更新中」及当前版本；断线和登录前探测失败也有兜底。每 3 秒探测恢复，同版本返回游戏，新版本沿用强制刷新机制。停服通知先写出，再同步保存并退出。
- 钓点钓速只乘算最终间隔，不进入上钩公式的 `speed` 变量。其他钓点增益继续参与对应公式。后台说明与实际计算一致；全服加成仍遵循原规则，与钓竿词缀相加后截断。
- 社交新增个人好友列表（最多 200 人），支持在线搜索、添加、移除及离线保留；搜索结果只有添加按钮。属于个人收藏式好友，不发送好友申请，也不自动写入对方列表。
- 人数广播补齐钓点人数，客户端缺字段时保留现状，真正离开时仍归零；好友在线状态每 5 秒刷新。
- 重铸成功保留组件和目标词条，可勾选不再显示成功页面，偏好保存在浏览器。材料消耗确认保留。
- 市集购买原位更新数量、移除售罄行、更新计数，保留其他挂单节点和筛选；余额不足点击购买／买满会显示反馈。
- 熔炼催化剂选择显示当前主件部位对应的词条区间，使用与熔炼预览相同的规则。
- 管理员六位动态密码输入完成后自动提交，处理中防重复；反馈状态修改原位更新徽标和计数，保留滚动、折叠与草稿，失败恢复原值。

新增独立回归：social-friends 16 项、admin-interactions 9 项、workshop-market-regression 9 项、update-page 5 项通过。Wiki 规则套件新增 3 项正负钓点钓速隔离回归，版本记录同步后复验共 97 项通过。新增套件均纳入 `tests/run-all.js`，无截图验证。
