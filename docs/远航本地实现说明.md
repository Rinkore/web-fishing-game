## 玩家入口与完整循环

原有“远洋”页面新增“远航派遣”和“套装核心兑换”，沿用现有船升级、背包、图鉴、钓竿装配、工坊、市集和玩家交易。原本消耗海图开放临时钓场的按钮改为“探索临时海域”，避免与新增的离线派遣混淆。

1. 船级逐步开放沿岸贸易 Lv1、深海采集 Lv2、沉船打捞 Lv3、凶险远征 Lv4、海王航线 Lv5。
2. 每次选择 2 / 8 / 12 小时，只能有一趟未领取航次。前三趟沿岸贸易免费，之后每趟消耗 1 片深海鳞片。
3. 服务器在出发时保存时间、船级、装备效果和固定随机结果，关闭页面、重启服务、途中换装都不会重掷本次奖励。未到返航时间不返回奖励明细。
4. 返航后手动领取金币、材料、船经验及成功印记。远航不产鱼，不写入鱼类图鉴、体型记录或排行榜。
5. 成功基础印记为 1 / 5 / 8。账号首次成功另给一次整套自选资格，可以保留到船级解锁所需套装；此后各航线 8 / 12 小时首次成功另给 10 / 15 印记。失败没有印记，普通失败保留约一半收益。
6. 船经验写入原有船成长账本，升级仍消耗原系统要求的金币、鳞片并校验经验。远航不是另建一条船等级。

航线基础成功率为 100 / 90 / 80 / 65 / 65%。稳定采用递减收益，额外成功率趋近 25 个百分点；普通材料收益加成最多 30%，8 小时及以上的结算加成最多 20%。整数材料按向下取整、最低 1 个结算，故极小产量不保证精确等于百分比。

## 七个位置、九种催化剂

竿身和饰品为两个套装核心位置；线组、钩、饵、卷线器、配件为五个普通位置，共新增 24 个普通底材。新底材的词条按部位限制：

| 普通位置 | 可出现及改造的属性 |
| --- | --- |
| 线组 | 钓速、稳定、材料概率 |
| 钩 | 技巧、体型 |
| 饵 | 稀有度、双钓、共鸣 |
| 卷线器 | 钓速、结算、稳定 |
| 配件 | 材料概率、共鸣、结算 |

自动配装保留已选套装核心，只优化其余组件；更换套装需手动选择。自动配装求解和实际装配顺序遵守同套核心与共鸣限制。

同一根竿最多装两件带共鸣的普通组件。该限制不把固定套装核心算入普通件数量。背包、组件筛选、市集和工坊接入稳定、共鸣、结算三个新属性及图标。

| 催化剂 | 对应属性 | 唯一常规产出航线 |
| --- | --- | --- |
| 潮汐砂 | 钓速 | 沿岸贸易 |
| 防腐盐 | 结算 | 沿岸贸易，8 / 12 小时 |
| 磨石粉 | 技巧 | 深海采集 |
| 腐殖泥 | 材料概率 | 深海采集 |
| 稳舵配重 | 稳定 | 沉船打捞 |
| 共鸣结晶 | 共鸣 | 沉船打捞，8 / 12 小时 |
| 星辉粉 | 稀有度 | 凶险远征 |
| 巨兽骨粉 | 体型 | 凶险远征 |
| 龙鳞碎屑 | 双钓 | 海王航线 |

这九种材料可在玩家间交易，不可卖给系统；默认商城和悬赏移除其产出，在线垂钓和商城后端拒绝发放，旧自动出售配置也不能卖掉它们。自定义悬赏如果仍配置专属催化剂，领取会被拒绝，须由管理员修正规则。管理员主动赠送资产仍属于管理能力。

鱼饵包、绳索、旧拟饵保留为基础熔炼燃料：提高熔炼成功率，不提供新增属性，也不增加催化补缀概率。同步修正了旧公式将负的“失败率增量”反向应用到成功率的问题。沉船宝匣残片和龙宫宝珠继续履行原有开箱、保护、重铸职责。

套装核心固定数值，可交易，不能熔炼、作为副件消耗、锻造或重铸；两件核心必须同套才能装配并激活。普通新组件的熔炼、锻造、神话生成均遵守部位属性池。

## 与设计稿的具体落地差异

- 航线等级优先采用首份船成长推进页；补充稿的四条基础航线之上增加 Lv5 单人海王航线，提供龙鳞碎屑。多人联合打捞、四人海王远征和船队专精属于后续扩展，本次未实现。
- 第八套“商路观测”按稿件的待企划状态保留。当前是七套可用、八套展示，不声称八套均已实现。
- 专属效果中的抽象数值（例如目标锁定、未知鱼情报）使用现有九种属性和套装行为表达；未创建一组只显示、不参与计算的假属性。
- 猎王追踪按有鱼的服务器结算段累计，支持玩家选择鱼种；不跨钓场生成本来不在池中的鱼。
- 考古的“提高下一次宝匣选择权”具体化为每六条线索自动发放深海珍匣，复用现有自选开箱功能。
- 旧组件保留解析、装备、交易和改造能力，不删除、不强制转换旧资产，但不再由新掉落或新宝匣产生。新普通部位最多有两或三类合法属性，因此新神话件填满本部位属性池，不承诺四种池外属性。
