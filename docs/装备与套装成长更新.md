- 「远航与套装」面板在任何装备制下都保留催化剂产出表（新制下折叠并注明不再随航次发放）；玩家进度编辑保留旧制船长字段并标注其不再参与计算。

- 修复：保存时给套装核心属性写入 0 值词条（未声明的属性不再写回）、装备面板在非安全上下文下 `crypto.randomUUID` 未兜底导致保存抛异常、远洋配置对越界输入的静默夹取改为显式报告。

## 批量转换与配装（v0.22.1）

- 工坊「旧制转换」支持逐件勾选、选择筛选结果中的前 100 件和清空选择；转换前展示整批材料费用及凭证补偿。装配占用的装备不允许转换。批量和单件转换共用资产事务与请求幂等，整批统一扣费，任一失败全部回滚。
- 装备成长支持部位、品质、属性、等级和绑定/占用状态筛选；成长转移可筛选目标绑定状态。背包、装备选择、交易、市集上架和配装器复用装备成长与绑定筛选。
- 配装器只列出已拥有完整竿身、饰品的套装，选择后固定核心。其余五部位可自动优化、固定指定配件或固定空置；成长词条按当前规则计算，套装触发收益单独生效。换装前同步服务器状态，先卸下冲突的旧核心与共鸣件，再安装新配件。
- 好友列表每页 20 人，更新保留页码，删除末页最后一人时自动回到有效页。在线好友可直接使用已有交易申请流程。
- 本次不新增数据库迁移。手动发布可在同一提交已完成本地验收后跳过重复 CI，仍执行部署健康检查与失败回滚。

本次将玩家工坊的装备操作合并为装备成长与套装成长，保留开箱。装备不使用经验；远航已有船只经验仍保留。

## 默认规则

- 五个普通部位：鱼线、鱼钩、拟饵、卷线器、配件。每件固定一条主属性，+4 解锁一条可选择的副属性，强化上限 +12。
- 强化采用确定性材料消耗；+4 起或完成精工后绑定角色，成长转移保留绑定。旧制普通配件提供确认转制入口。
- +8 开放主属性或副属性精工，两种方向互斥。纯材料精工和热量优惠精工提供相同属性；工匠进阶可降低热量费用、切换已制作的预设。
- 强化合金、精工合金、熔炼催化晶为远航成长资源；原有船只、海图与宝匣资源继续保留其既有来源。每累计领取 8 小时远航获得一张角色绑定航程凭证。
- 竿身和饰品作为钓鱼套装核心；同套两件激活。四套为锻造工匠、丰收渔获、猎王追踪、生态培育。
- 生态培育以 5% / 6% / 7% / 8% 的概率混入同区间均匀体型分布，适当增加大小两端的出现机会，保持原体型范围与后续体型加成。
- 潮汐采集、沉船考古、风暴远洋、救生护航作为独立远航专精，使用金币和材料独立解锁，无需竿身、饰品。派遣时选择专精，钓竿属性不参与远航计算；出发后奖励与规则锁定。
- 套装及远航专精共有基础、1、2、3 四阶段。钓鱼套装通过金币、材料、航程凭证与同套重复核心进阶，保留每个核心部位至少一件；远航专精只消耗对应金币、材料和航程凭证，不再要求或消耗装备核心。

## 后台入口

“装备与套装”管理成长等级、属性曲线、副属性方向、各项操作费用与材料、核心基础属性、套装和远航专精全部阶段参数、追踪保底覆盖与排除鱼种、远航基础材料、旧制转换补偿，以及玩家成长进度。支持完整配置导入导出。

“远航与套装”继续管理航线、船级门槛、门票、兑换印记和航次提前结算；新成长数值统一在装备管理页维护。旧熔炼、重铸与随机锻造入口在新制开启时明确拒绝操作。

服务端复用资产事务、请求幂等、配置发布及推送机制；装备成长状态由新增的 `0032_gear_growth.sql` 保存，绑定转移有数据库约束。远端已有 `0030_legacy_economy_history.sql` 和 `0031_mail.sql` 保持原编号。

## 远洋菜单与独立专精调整

远洋按「远航中心」「船坞与海图」「每日悬赏」分区；远航中心设「远航派遣」「专精配置」「专精成长」「钓鱼套装」「返航记录」子菜单。当前航次和返航领取常驻远航中心。切换菜单与状态刷新保留派遣选择。工坊只管理四套钓鱼套装及钓鱼偏好。

新制启用时，远航兑换仅提供四套钓鱼装备；四项专精直接复用成长接口解锁和进阶。已有专精等级、解锁状态、正在航行的快照及历史核心保持原状，不执行资产删除或自动转换。历史核心不再是专精认证条件，也不再被专精进阶消耗。后台仍保留历史物品定义用于兼容。

专精配置总配额为 3 点，可分配为 3、2+1、1+1+1，也可留空。专精成长阶段与投入点数分别保存；收益按投入点数 / 3 发挥，三点集中保留完整效果。配置在独立页面保存，启航页仅展示已保存摘要，并由服务端读取保存方案生成出发快照。未保存草稿与后续配置变化不影响已出发航次。
