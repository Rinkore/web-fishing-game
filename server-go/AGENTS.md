# Go 重构实施约定

遵循仓库 AGENTS.md 和 docs/go-architecture.md。用户已确认正式版本 v0.21.4，并明确现在不做数据迁移；运行中复制的存档仅供参考。当前推进 Go 基础工程与合成数据验证，正式迁移在后续停服阶段独立验收。

- Go 版本以 go.mod 为准。入口放 cmd，业务按 internal/modules 划分；有实际用例后再添加模块，避免空接口。
- 旧存档只读；扫描不调用旧服务端、不迁移旧目录、不自动修复资产、不打开正式数据库。私有样本和报告放仓库忽略的 migration-private/ 或仓库外。
- 扫描报告不得包含账号名、原文件名、密码哈希、会话、MFA、QQ 或存档原文。解析错误输出固定错误码。
- 源码接口清单是静态候选，不是已验收 OpenAPI。变更后重新生成并审阅差异；不得为通过测试而无说明地刷新规则样例。
- 涉及资产、权限、schema 或调度时，补充并发和失败路径，执行真实 PostgreSQL 集成测试后才可声称数据库保证已实现。
- 提交前运行 gofmt、go build ./...、go vet ./...、go test -count=1 ./...；测试输出仅保留末 40 行。并发代码需运行 race 检测，发布覆盖 Linux。
- 本阶段没有自动导入、正式服切换或部署命令。基础工程与隔离环境原型可先行；正式数据核查延期不代表迁移、容量或生产放行条件已经通过。
